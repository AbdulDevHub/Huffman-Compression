# Huffman Zip [Compress & Uncompress Any File]

<img height="400" src="TestFiles/zip.jpg">

> A Python-based implementation of the Huffman Compression Algorithm for lossless file compression and decompression via the command line.

## Overview

This repository contains a Python program that uses **Huffman binary trees** to perform **lossless compression and decompression** on any file. The tool works directly from the console and supports both compressing and restoring files to their original form.

The goal of this project is to explore data compression techniques while maintaining efficiency and correctness.

## Features

- Lossless file compression and decompression
- Uses Huffman binary trees
- Supports compressing **any file type**
- Average compression ratio of approximately **1.5:1**
- Command-line based workflow
- Optional runtime and compression profiling

## Setup

To run this program locally, follow these steps:

1. Clone the repository  
2. Navigate to the project directory  
3. Install the required libraries  
4. Run the desired script from the command line  

## Usage

The repository provides multiple entry points depending on your goal:

- **`compress.py`**  
  Run this script to compress or decompress a file by providing a file path.

- **`profile.py`**  
  Run this script to profile compression and decompression performance, including runtime and compression ratios over multiple iterations.
